# 拍档 Logo

## 给设计工具的一句话介绍（拿去喂 ChatGPT / 设计师）

> 拍档是一款面向网球陪练教练的生意经营工具（微信小程序）：学员在线预约时段、扫码收款自动记账、学员档案与课后备注管理；Slogan 是「好生意，需要好拍档」。Logo 要极简克制、艺术化：只用墨黑 #1a1a1a、米白 #fafaf8、苔绿 #2f5d3a 三色，禁用渐变、装饰元素和 emoji 风；主要用在 App 图标和小程序启动页。

## 三版方案（SVG 矢量，可直接用）

| 文件 | 方案 | 立意 |
|---|---|---|
| `paidang-logo-seal.svg` | 印章款 | 墨底白字，像一枚私章；App 图标场景最稳，缩小也清晰 |
| `paidang-logo-ball.svg` | 网球线稿款 | 一个圆 + 两笔苔绿弧线即网球；字标「拍档 PAIDANG」在下 |
| `paidang-logo-doubles.svg` | 双打款 | 两环相交——两个人、双打、拍档；呼应「工具是陪练的生意拍档」 |

设计语言依据 `../DESIGN.md`：极简、克制、三色以内、不要 AI 味。
