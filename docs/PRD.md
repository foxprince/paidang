# 拍档 · PRD（MVP）

## 产品定义
给网球陪练的经营工具：预约 + 收款 + 学员管理。陪练 5 分钟生成个人预约主页，学员扫码自助下单，陪练微信里确认、收款、记账。

Slogan：好生意，需要好拍档。

## 用户
- **陪练端**：会打球、靠陪练赚钱的人。微信登录，用全部功能。
- **学员端**：想找陪练的人。免登录，打开主页就能预约。

## 功能

### F1 微信登录
陪练用微信一键登录。服务端用 code 换 openid（code2session 只在服务端调），签发 JWT（7 天有效期）。
学员端不需要登录。

验收：新陪练首次登录自动建档；token 过期后小程序静默续登。

### F2 陪练个人主页
陪练的一张体面名片，学员扫码看到：
- 头像、昵称、头衔、简介、常出没球场
- **30 秒对打视频（必填）**——没视频不给发布
- 价格/小时、可约时段、微信收款码
- 平台验证徽章（人工审核后发放）
- 评价列表（仅已完成订单可评价）

可生成小程序码，陪练发到朋友圈、球友群。

验收：信息不全不能发布；视频缺失时发布按钮置灰并提示原因。

### F3 在线预约
学员在陪练主页选日期时段，填姓名 + 手机号（短信验证码），提交。

状态机：
```
待确认 → 已确认 → 已完成
   ↓         ↓
已取消     已取消
```
规则：
- 陪练在微信里确认或拒绝；拒绝要选理由
- 开课前 4 小时学员可免费取消，之后取消记一次爽约
- 陪练无故取消记一次爽约
- 爽约只记信用，不罚款（罚金是 Pro 阶段的事）

验收：从下单到确认全程不超过 3 步；重复提交不产生重复订单（幂等）。

### F4 手动收款确认
平台不碰钱。学员线下扫陪练的微信收款码付款，陪练在订单上点"确认收款"，流水入账。
- 下单时明确提示：单次付款，不要大额预付
- 陪练 24 小时未确认收款，订单标为"待对账"提醒

验收：确认收款后收入看板实时更新；未确认的订单不计入收入。

### F5 学员管理
学员列表（按最近上课时间排序）、详情、水平标签。
核心是**按次课备注**：每次课后记三行——日期、本节要点、下节计划。陪练的备课本。

验收：备注支持按学员回看时间线；换手机不丢数据。

### F6 收入看板
一本干净的账：
- 本月实收、上月实收、订单数、课时数
- 按学员统计：谁贡献了多少课时

验收：数字 = 已确认收款订单之和，对得上，一分不差。

### F7 今日课表
陪练端首页。当天课程按时间排成一条线：时间、学员、状态。
- 待确认的订单置顶，一键确认/拒绝
- 已确认的临近开课，一键"开始上课"→"完成"

验收：打开首页 1 秒内看到今天有没有课；误操作可撤销（完成前）。

### F8 微信预约通知
订阅消息，四种：
- 有新预约 → 推给陪练
- 陪练确认/拒绝 → 推给学员
- 开课前 2 小时 → 推给双方
- 订单完成 → 推给学员，附评价入口

学员下单时一次性申请订阅，不反复打扰。

验收：四种消息在真机可收到；用户拒绝订阅不影响下单。

## 信任与纠纷
平台做"大众点评式信用"，不做"支付宝式担保"：
- 主页必填对打视频；评价仅已完成订单可写
- 预约前公示取消/爽约规则；提示单次付款、不预付大额
- 学员可提交付款截图 + 聊天记录投诉，平台 48 小时内处理
- 投诉成立记公开履约污点；累计两次下架主页，三次封号
- Pro 阶段再考虑 500 元保证金先行赔付

## 非功能
- 安全 P0：JWT、接口限流、参数化查询、上传大小限制、HTTPS、手机号脱敏（中间四位星号）、密钥全走环境变量
- 备份：数据库每日自动备份，保留 30 天
- 性能：首页接口 P95 < 500ms

## 不做（MVP 范围外）
在线支付/分账/资金托管；拼单/团课；罚金执行；青少年培训（资质红线，MVP 只服务成人陪练）。
